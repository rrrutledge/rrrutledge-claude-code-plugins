# rrrutledge-claude-code-plugins

A curated collection of [Claude Code](https://claude.ai/code) plugins by Russell Rutledge.

## Install

```
/plugin marketplace add rrrutledge/rrrutledge-claude-code-plugins
```

Then install individual plugins:

```
/plugin install <plugin-name>@rrrutledge-plugins
```

## Plugins

### [browser-chauffeur](plugins/browser-chauffeur/)

Browser automation with self-healing recovery. Tell Claude what you need done on a website - browser-chauffeur handles the rest. Claude is your chauffeur: you give directions, Claude drives.

```
/plugin install browser-chauffeur@rrrutledge-plugins
```
